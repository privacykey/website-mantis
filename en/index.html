architecture

Three pieces.

A CLI, and a server in two shapes. Pick the one that fits how you want to run it; the same CLI mints against both.

// controller

mantis CLI

Terminal client. Mints keys, tails hits, generates baited files and host-event snippets.

  • mantis new · list · hits · watch · install
  • Credentials in your OS keychain
brew install privacykey/tap/mantis
// self-hosted server

mantis full

Stateful. Next.js + Postgres, web dashboard, REST API, retry queue.

  • Dashboard · timeline · multi-destination · revocation
  • Docker · Railway · Fly · Render · any VM
docker compose up -d
// stateless worker

mantis edge

Stateless. One Cloudflare Worker, no database — the URL itself is the state.

  • Anycast at 300+ PoPs · sub-50ms · free tier
  • Anyone with the AES key can mint
pnpm exec wrangler deploy

what mantis catches

One URL, many traps.

Plant the same URL in ten file formats, twelve host events, two web embeds, NFC tags, and Apple Wallet passes. Every trap fires the same key.

armed file-keys/01

Insider snooping on baited documents

Generate .docx, .xlsx, .pptx, .pdf, and six other formats with the URL embedded. Drop one on a shared drive. When someone opens it, mantis fires.

armed file-keys/02

The honey directory

One zip, nine pre-baited files — salary spreadsheet, layoff PDF, fake passwords.txt. A curious spelunker opens any of them and the same key fires.

armed host-events/01

Unfamiliar activity on your computer

Twelve installers for shell, sudo, login, boot, wake, Wi-Fi join, VPN, Ethernet. SSH sessions report the client's IP, not yours. macOS, Linux, Windows.

armed smart-home/01

Smart-home & IoT — both ways

Door opened. Lock unlocked. Person detected. Snippets for Home Assistant and Scrypted turn any automation event into a hit; a LAN watcher covers devices with no webhooks. And it runs in reverse — a hit can post back to a Home Assistant webhook to flip a switch, fire a scene, or cut a VLAN.

armed web-embed/01

Cloned sites & copied stylesheets

Hide the URL in your CSS or JS. If a phishing kit copies it to another domain, the rendered page calls home with the cloner's referer.

armed physical/01

Tapped tags & wallet passes

Write the URL to a blank NFC tag (NTAG213/215/216), or print a QR/NFC sticker label. Or mint an Apple Wallet .pkpass — its install, uninstall, and fetch callbacks each fire the key.

armed notify/01

Fan out through your existing alerting

Native: webhook, email, Slack, Discord, Teams, Home Assistant. Plus a per-key status URL Uptime Kuma can watch — inherit its 80+ channels (Telegram, ntfy, Matrix, Signal).

armed reliability/01

Quiet under load, loud when it matters

Dedupe window suppresses repeat-fire notifications. Postgres-backed retry queue with exponential backoff. No Redis, no silent failures.

choose your shape

Two servers. One CLI.

Both servers are controlled by the same mantis binary — same install (brew install privacykey/tap/mantis), same command surface, same hit payload shape. The mint path is the only thing that differs.

stateless variant

mantis edge — the URL is the database.

One Cloudflare Worker, no database. The trigger URL itself is an AES-encrypted blob carrying the webhook destination — on hit, the Worker decrypts, forwards, and forgets. Your webhook receiver is the audit log.

shelldeploy + mint
# 1. Generate the 32-byte AES key that mints + decrypts URLs.
$ mantis edge keygen

# 2. Store it as a Worker secret on Cloudflare.
$ pnpm exec wrangler secret put MANTIS_EDGE_KEY

# 3. (Optional) restrict webhook destinations to specific hosts.
$ pnpm exec wrangler secret put MANTIS_EDGE_WEBHOOK_ALLOWLIST

# 4. Ship the Worker.
$ pnpm exec wrangler deploy
  → https://mantis-edge.<subdomain>.workers.dev

# 5. Tell the CLI which Worker to mint against; save the key locally.
$ mantis edge set-key https://mantis-edge.<subdomain>.workers.dev

# 6. Mint a URL. No round-trip — the URL is generated locally.
$ mantis edge mint \
    --worker https://mantis-edge.<subdomain>.workers.dev \
    --webhook https://hooks.slack.com/services/... \
    --channel slack \
    --memo "edge smoke test" --test

how it works

  • mantis edge mint runs locally — the URL encodes the webhook, channel, and memo. No Worker round-trip.
  • On hit, the Worker decrypts and forwards. Formats for slack / discord / teams if requested.
  • MANTIS_EDGE_WEBHOOK_ALLOWLIST restricts where URLs can fire — defence in depth if the AES key leaks.

Full walkthrough at mantis-docs.privacykey.org/edge-deployment.

[!] trade-offs No dashboard, no key list, no retry queue, no central audit log — the webhook receiver records everything. Anyone with the AES key can mint. Need any of those? Use mantis full.

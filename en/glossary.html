glossary

Mantis words, explained.

Use your browser's Find command to find a word. Entries are in alphabetical order. In this site, “mantis” is pronounced “MAN-tiss,” like the insect.

Terms and abbreviations

AES
Advanced Encryption Standard. A way to turn readable data into encrypted data. Edge uses a shared secret key to encrypt and read its URLs.
AGPL
GNU Affero General Public License. A software licence. Its exact version and terms matter; follow the licence link on the licences page.
API / REST API
Application programming interface: a way for programs to talk to each other. REST means Representational State Transfer, a common style of web API.
APNs
Apple Push Notification service. An Apple service that delivers push messages to supported devices.
AWS
Amazon Web Services. A cloud service provider. Mantis can create bait that looks like an AWS credential profile.
Backend
The part of Mantis that receives requests. Choose the full server or the edge Worker.
Bait / canary / tripwire
Something placed where unexpected use would be worth checking. In Mantis, it contains or uses a unique web link. The words describe the same basic idea here.
CI
Continuous integration. Automated checks run when code changes. The main CI badge reports the checked run on the main source branch.
CLI
Command-line interface. A program you use by typing commands in a terminal.
CPU
Central processing unit. The part of a computer that runs instructions. CPU time counts active processing, not all time spent waiting for a request.
Credential
Information used to gain access, such as a password or secret key. Fake credential text only triggers Mantis if its embedded address is used.
CRT / DEC
CRT means cathode-ray tube, a type of older screen. DEC means Digital Equipment Corporation. These names describe the look of two color themes.
CSS
Cascading Style Sheets. Rules for how a web page looks. A CSS rule can load a Mantis URL as an image.
CSV / TSV
Comma-separated values and tab-separated values. Text table formats, often used to create many keys at once.
Dashboard
A web page that brings controls and results together. Mantis full has one; edge does not.
Database / Postgres
A database stores information in an organized way. PostgreSQL, often called Postgres, is the database used by Mantis full.
Deduplication
Treating repeated events as one for a chosen period, to reduce repeated alerts.
Deploy
Set up a program on a computer or service so it can run and receive requests.
DNS
Domain Name System. It helps a browser find the server for a name such as example.com.
DOCX / XLSX / PPTX
File extensions for modern Word documents, Excel spreadsheets, and PowerPoint slides. They are Office Open XML formats.
Edge / Worker
Mantis edge runs as a Cloudflare Worker: a small program hosted by Cloudflare. It reads settings from an encrypted URL and sends the event to another service.
EML / ICS / VCF
File extensions for an email message, an iCalendar calendar file, and a vCard contact file. VCF is also called a Virtual Contact File.
Encryption / AES key
Encryption hides readable data with a secret. The AES key is that secret for Mantis edge; it is different from an individual tripwire URL.
Enrollment / fleet
Enrollment sets up a device to use a service. A fleet is a group of devices managed together.
Fetch / GET / request
Asking a server for something at a web address. GET is the HTTP method used to request a resource. A person, program, or scanner can make a request.
Full
The Mantis server that stores keys and hits, offers a dashboard, and retries failed alerts.
GNU
GNU's Not Unix. The name of the free-software project associated with the GPL and AGPL licences.
Hex color code
A color written as # and six digits or letters. The allowed symbols are 0–9 and A–F. For example, #ffffff is white and #000000 is black.
Hit
A request received at a Mantis tripwire URL. It is evidence of a request, not proof of a person's identity.
Honey directory
A group of bait files packaged in a ZIP file. Opening the ZIP or reading plain text alone does not make a request.
HTML
HyperText Markup Language. The format used to give web pages their content and structure.
HTTP / HTTPS
Hypertext Transfer Protocol, and its secure form. The rules browsers use to request web content. HTTPS encrypts the connection.
ID / UUID
Identifier, and universally unique identifier. A value used to tell one record, key, or device from another.
IP address
Internet Protocol address. A network address seen with a request. Shared networks and proxies mean it may not identify a particular person.
JS / JSON
JavaScript is a programming language used on web pages. JavaScript Object Notation is a text format for exchanging data.
Key
On this site, a Mantis key is a unique tripwire record or URL. An edge AES key is a different thing: the secret used to encrypt edge URLs.
LAN
Local area network. A network in a home, office, or other local place.
Licence / MIT / GPL
A licence sets terms for using code. MIT is the name of a licence originally associated with the Massachusetts Institute of Technology. GPL means GNU General Public License. Check the exact licence text for its terms.
Local storage / cache
Data kept by your browser for this website. A cache keeps a recent result so it does not need to be requested again right away.
NFC / NDEF
Near-field communication lets nearby devices exchange data, as when a phone taps a tag. NFC Data Exchange Format is a way to store data such as a URL on that tag.
PDF
Portable Document Format. A document format. A PDF reader may require a link click before it requests the embedded Mantis URL.
Pre-1.0 / release / main
Pre-1.0 means the software has not reached version 1.0. A release is a published version. Main is the current development branch and may be newer than a release.
Provisioning
Preparing devices or accounts with the settings and access they need.
QR
Quick Response code. A square printed pattern that can hold a URL. A scan must open the URL to create a hit.
Queue / retry / backoff
A queue holds work to do. A retry tries failed work again. Backoff leaves more time between later retries.
Referrer / user agent / UA
A referrer can identify the page a request came from. A user agent describes the browser or program making a request. These fields can be absent or misleading. UA is short for user agent.
Revoke
Stop a key from working. Full can disable one key; rotating the edge AES key affects every URL made with the old secret.
RTF / TXT
Rich Text Format supports styled text. TXT marks a plain-text file. Reading plain-text bait alone does not make a request.
SSH / SSO
Secure Shell is used to connect to another computer. Single sign-on lets one account sign in to several services.
Stateful / stateless
Stateful software keeps records between requests. Mantis full stores keys and hits. Mantis edge is stateless: each URL carries its settings instead of using a central key list.
sudo
A command used to run another command with another user's privileges, often an administrator's. Its name is commonly read as 'soo-doo' or 'soo-doh'.
URL / endpoint
Uniform Resource Locator: a web address. An endpoint is the address where a service receives a particular kind of request.
VM
Virtual machine. A software-based computer running within a larger computer.
WCAG / AAA
Web Content Accessibility Guidelines. Level AAA is the highest of the three WCAG conformance levels. It includes the requirements of Levels A and AA.
Webhook
A web address that a service sends an event to. Mantis can send hit details to a webhook you choose.
ZIP
A common archive format that packages files together, often using less storage. ZIP is a format name rather than an acronym.

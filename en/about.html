about

A trap that calls home.

mantis mints canary tokens: ordinary-looking URLs that sit inside files and systems and call home when something fetches them. Named for the praying mantis: still until provoked, fast when it isn't.

Why it exists

Most breaches involve a moment of curiosity nobody saw at the time: a file opened on a share, a stylesheet copied to a phishing clone, a stale credential reused. A canary turns that moment into a signal. Thinkst's Canarytokens proved the pattern; mantis is the self-hostable version.

What it does

  • Mints unique URLs tied to a memo and notification destinations.
  • Generates ten kinds of baited file (.docx, .xlsx, .pptx, .pdf, .svg, .html, .md, .eml, .ics, .vcf).
  • Generates installers for twelve host events on macOS, Linux, and Windows.
  • Generates CSS and JS web-embed snippets, NFC tags, and Apple Wallet passes.
  • Routes hits to webhook, email, Slack, Discord, Teams, or Home Assistant, or via Uptime Kuma to its 80+ channels.
  • Runs both ways: a hit can drive a Home Assistant action (flip a switch, fire a scene, or cut a VLAN).

What it doesn't try to be

mantis isn't a SIEM. It turns a fetch of a unique URL into a notification, and that is the entire surface area. For correlation, dashboards across many signals, or SOC workflows, point a real platform at mantis's webhooks.

It also isn't invisible to a determined adversary. File keys leave OOXML / PDF artefacts; host snippets leave a script on disk; CSS canaries render a 1×1 image. mantis targets curious insiders and opportunistic attackers, not forensic auditors.

Three pieces

  • CLI: terminal client, mints keys and generates installers. brew install privacykey/tap/mantis.
  • mantis full: self-hosted Next.js + Postgres with a dashboard and REST API. Docker, Railway, Fly, Render.
  • mantis edge: stateless Cloudflare Worker; the URL itself is an AES-encrypted blob, the webhook receiver is the audit log. Free tier covers personal use.

Status

CLI v0.2.0 · full v0.1.1 · edge v0.1.3, MIT-licensed, a privacykey project. Everything in the feature list above is shipping; the roadmap lives in the mantis docs.

Open-source libraries & licences.

mantis is built on open-source software. This page lists the major third-party libraries the project depends on, across the website you're reading, the mantis full server, the mantis edge Worker, and the mantis CLI. They are grouped by SPDX licence identifier. Where the chip says site only, the library is only used to render this marketing site; everything else is part of the mantis software you'd install.

PostgreSQL

mantis full

Relational database. Stores keys, hits, API keys, and the notification retry queue. mantis full uses FOR UPDATE SKIP LOCKED on the queue, so multiple worker instances are safe to run side by side.

Hosted services (not bundled)

These aren't libraries you can vendor. They're Cloudflare's hosted platform. Listed here for completeness because mantis edge depends on them at runtime. Terms are governed by Cloudflare's own agreements rather than an open-source licence.

Cloudflare Workers

mantis edge

The serverless platform mantis edge runs on. A single Worker handles the public trigger endpoint, decrypts the AES blob in the URL to recover the webhook destination, and forwards the hit. It uses no D1, KV, or Queues. The URL itself carries every byte of state the Worker needs.

A note on completeness

The list above covers the major direct dependencies, the libraries you'd notice if they disappeared. The full set, including transitive dependencies, lives in the lockfiles in the mantis repository (package-lock.json for npm, Cargo.lock for any Rust components, requirements.txt for any Python tooling). If you spot something missing here that should be called out, especially anything with a copyleft or attribution-required licence, please open an issue and we'll add it.

Last updated May 2026. Versions track the current main branch; if you're running a pinned release, your specific versions are in that release's lockfile.

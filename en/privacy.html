privacy

What happens when you visit.

This website uses no analytics scripts, advertising trackers, or fingerprinting. Its pages, scripts, and images—including the maker avatar—are served from this website's origin. Text uses your system's fonts.

Hosting

Cloudflare serves this website and processes requests to deliver and protect it. That includes connection information such as your IP address, requested URL, and browser headers. Hosting and security records are separate from analytics scripts; this site does not promise that its host keeps no logs.

Cloudflare's privacy policy ↗

The GitHub CI badge

The footer makes one anonymous request to GitHub for the latest main-branch push run of the CI workflow in the Mantis product repository. This is the only direct request the page's scripts make to another origin.

GitHub public REST API

https://api.github.com/repos/privacykey/mantis/actions/workflows/ci.yml/runs?branch=main&event=push&per_page=1
When
On page load when a valid cached result is unavailable. Successful results are cached for five minutes.
Sent
A GET request with standard browser/network information, including your IP address. The request explicitly omits cookies and the referrer; no API key, account identifier, or demo input is sent.
Received
The run's status, conclusion, and link. The footer displays when it last checked.
Optional
You can block api.github.com with your browser or content blocker. The badge then shows that status is unavailable. The rest of the site still works.

GitHub's privacy policy ↗

What stays in your browser

The site sets no cookies. It writes two small localStorage entries, which you can clear in your browser settings:

  • mantis-theme remembers your selected theme: mono, amber, phosphor, cyan, ultraviolet, rust, paper.
  • mantis-main-ci-v1 caches the main CI result and the time it was checked for five minutes.

If browser storage is unavailable, the page still works. The interactive terminal is a simulation: its inputs and temporary keys stay in the page's memory and disappear when you reload. It does not create real keys or send notifications.

When you follow a link

Opening documentation, GitHub, or another external link sends a normal page request to that destination. Its own privacy policy then applies. External pages are not loaded as embeds.

The Mantis software is separate

A Mantis full server records configured hit information in your Postgres database and sends notifications to the destinations you choose. Edge processes traffic on Cloudflare and forwards it to the webhook encoded in a key. Notification providers and optional integrations, such as Apple Wallet push services, have their own data handling.

See the configuration reference and operational notes for deployment behavior.
